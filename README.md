# 💻 Advanced JavaScript Foundations & Core Patterns

[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A foundational engineering repository exploring advanced JavaScript concepts, lexical scoping, closures, prototype inheritance, and modular code patterns.

---

## 📚 Topics Covered
- **Closures & Lexical Scoping**: Private variables, function factories, and memoization.
- **Execution Context & Hoisting**: Global execution context, Call stack phase breakdown, Temporal Dead Zone (TDZ).
- **Prototypal Inheritance**: Object prototypes, prototype chain lookups, and ES6 class syntax desugaring.
- **Functional Programming Primitives**: Currying, composition, pure functions, and immutability.
